# Native formatting fixtures

These fifteen complete `.inp` files were created by ImadC9 for this experiment
in the InPage2014 Khattat Professionals installation. They are contributed
under the repository's [MIT licence](../../../LICENSE), with the creator's
permission. They contain the short Urdu test line, not the third-party story
used by the separate legacy-structure study. The original file bytes have not
been sanitized, resaved, or regenerated by the research tools.

`../evidence.json` records the complete file and logical-stream SHA-256 hashes,
the intended experiment labels, and the measured formatting. Run
`python research/native-formatting/verify.py` from the repository root after
installing `research/native-formatting/requirements.txt` to check every file.

| File | Experiment |
|---|---|
| `01-baseline.inp` | Initial saved document; measured body is Naskh, 11 pt. |
| `02-control-a.inp` | Unchanged Save As; reference for comparisons. |
| `03-control-b.inp` | Independent unchanged Save As. |
| `04-control-c.inp` | Independent unchanged Save As. |

| `09-bold.inp` | Bold. |
| `10-italic.inp` | Italic. |

| `12-align-left.inp` | Left alignment. |
| `13-align-center.inp` | Center alignment. |
| `14-align-justify.inp` | Justified alignment. |
| `15-font-noori.inp` | Noori Nastaliq. |

All fifteen files were used for discovery; none is an independent holdout.
The creator confirmed successful native saving/reopening and identified the
producing installation. The About evidence is recorded in `../provenance/`.
The scripts verify file bytes, not native rendering or reopening.
